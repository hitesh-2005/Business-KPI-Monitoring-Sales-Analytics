# Executive KPI Monitoring Dashboard (Frontend)

Interactive executive monitoring dashboard built with **React 19, Vite, Recharts, Lucide Icons, and Tailwind CSS**.

This frontend dynamically consumes the analytics payload generated by the Python/SQL analytics pipeline (`dashboard_data.json`) and provides multi-dimensional filtering and visual analytics.

---

## Features & Visualizations

1. **Dynamic Payload Loading**: Fetches `/dashboard_data.json` with loading state, error boundary, and refresh button.
2. **Interactive Filters**:
   - **Time Range**: `30D` (Trailing Month), `90D` (Quarter), `1Y` (Trailing Year), `2014`, `2013`, and `ALL` (Full History).
   - **Region Dropdown**: `All Regions`, `West`, `East`, `Central`, `South`.
   - **Category Dropdown**: `All Categories`, `Technology`, `Furniture`, `Office Supplies`.
   - **Dynamic Recalculation**: Key executive KPI cards (Revenue, Profit, Margin, Orders, Return Rate) recalculate live to reflect active filter selections.
3. **Charts & Analytics Components**:
   - **Revenue & Profit Trend**: Dual-axis line/area chart with 7-day rolling average and statistical anomaly markers.
   - **14-Day Holt-Winters Forecast**: Future projections with upper and lower uncertainty bounds.
   - **Regional Performance**: Weekly breakdown with WoW growth and partial-week indicators.
   - **Category Margin Analysis**: Margin contribution and market share percentages.
   - **Top Products Table**: Top 10 revenue-generating products with profit margins.
   - **Live Operational Alerts**: Triggered threshold breaches and model anomalies color-coded by severity (`CRITICAL`, `WARNING`).

## Development & Build Commands

```bash
# Install dependencies
npm install

# Start local Vite development server
npm run dev

# Run Oxlint linting check
npx oxlint

# Build production bundle
npm run build
```

---

## Production Asset Location
The dashboard expects `dashboard_data.json` inside the `public/` directory (`kpi-frontend/public/dashboard_data.json`). Running `python scheduler/run_pipeline.py` automatically regenerates and synchronizes this file.
